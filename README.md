# 月あかりの谷

ブラウザーで遊べる、Canvas製の横スクロールアクションゲームです。宝石を集め、敵や谷のすき間を越えながらゴールの旗を目指します。

## 遊び方

`index.html` をブラウザーで開くか、リポジトリのディレクトリでローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザーで <http://localhost:8000> を開き、「冒険をはじめる」を選んでください。

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | `A` / `D` または `←` / `→` |
| ジャンプ | `Space`（`↑` / `W` でも操作できます） |
| ファイアーボールを撃つ | `X` |
| ゲーム開始・リトライ | `Enter` |

スマートフォンなどでは、ゲーム画面下のタッチボタンで移動・ジャンプ・攻撃ができます。

宝石を集めるとスコアが加算されます。敵はジャンプで踏むか、ファイアーボールで倒しましょう。ライフがなくなる前にゴールへ到達するとクリアです。ライフを3つ残してクリアするとボーナスが加算されます。

## ファイル構成

- `index.html` — ゲーム画面、HUD、開始画面、操作ボタン
- `style.css` — レイアウトとビジュアル
- `game.js` — ゲームの状態、操作、当たり判定、描画

ビルドツールや外部ライブラリは不要です。Canvasに対応したブラウザーで動作します。
